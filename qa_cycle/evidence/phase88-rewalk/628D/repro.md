## Fixer notes (facts found while reproducing)

- **DeleteGuard composes the noun itself.** `DeleteGuard.java:49,58,70` builds "Cannot %s **%s** with …" from `forEntity("customer"|"project", …)` and from resource strings such as "linked projects" and "invoice(s)". Rewriting only the remedy strings listed in R8 §1.5 would still leave "Cannot archive customer with linked projects". The `entityName` and `resource` arguments have to change too, at `CustomerService.java:778-787` and `ProjectDeletionGuard.java:36-52`.
- **The status guard** at `ProjectService.java:878-881` says "Cannot delete a closed project. Reopen the project first."
- **The `court_calendar` module id is load-bearing.** It gates `DiaryService:58`, `ProjectService:72`, `ProjectUpcomingDeadlinesService:65`, `CourtCalendarService:31`, `CourtDateReminderJob:24`, `PrescriptionTrackerService:28`, `ComplianceDataCollectorService:142`, `LegalDemoDataSeeder:371` (`registry.getModule("court_calendar").isPresent()`) and frontend `matter-tabs.tsx:119`. `VerticalModuleGuard.isModuleEnabled` reads the tenant's `enabled_modules`, not the registry. Those ids come from `resources/vertical-profiles/legal-za.json:5`, which lists `court_calendar`. `OrgSettingsService` already accepts ids the registry doesn't know (see the comment near `:451`, e.g. `deadlines`). So deleting the registry entry should not turn the module off. Two things still read the registry, though: `LegalDemoDataSeeder:371` (`getModule("court_calendar").isPresent()` decides whether demo court data is seeded) and the profile-switch horizontal filter (`OrgSettingsService` around `:1068`). Check both before deleting. The alternative is to rename the entry and drop the dead NavItem. That choice belongs to the orchestrator.
- **Stored notification rows will not change.** "You were added to project …" titles already in the DB keep their wording after a code fix; only new rows get the new text. `NotificationService.java:92` already documents this.
- **Platform templates are read-only in the editor** (`edit/page.tsx:37`, `readOnly = template.source === "PLATFORM"`). To observe the variable picker after the fix, use Settings › Documents › New Template.
- **This stack's Mailpit is on :8026.**
