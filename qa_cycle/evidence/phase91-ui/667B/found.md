## Not observable on this data (recorded so nobody claims them)

- **Monthly list flags** (`monthly-list-flags`, `lists/[listId]/page.tsx:141-167`): this is a `<ul>` with severity chips, **not a table**. The only locked list was frozen with `integrityFlags: []`, so the block is not rendered. A list with flags needs another completed reconciliation; this was not attempted, so unit tests must cover it.
- **667.7's "flags table (:185)"** is in fact the **"Entered after this list was locked"** table. It was made observable with one backdated deposit (`667B-AFTER-LOCK`; see `before/README.md`).
- **K-91's s86(3) note** (see F-667B-2).
- A `maturity-alert` row: neither investment has a maturity date.
- The take-on reports card on Trust Reports (no take-on on this stack).
