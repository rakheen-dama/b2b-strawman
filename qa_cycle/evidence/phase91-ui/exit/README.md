## Record schema (for M2: append records with your own `group`)

`measurements.json` and `console.json` are **single-line JSON arrays**. Writers replace only their own `group`'s records (`lib.cjs` `appendGroup(file, group, items)`), so M2 appends by calling `runGroup()` / `appendGroup()` with new group names.

- **`measurements.json`** — one record per page load: `group`, `surface`, `key`, `persona` (`alice` / `bob` / `carol` / `anon`), `variant` (e.g. `1024-light`, `1440-dark`, `390-light`, or a custom id such as `1440-stored-dark`), `w`, `h`, `storedTheme` (value the init script put in `localStorage["kazi-theme"]`, or null), `expectDark`, `url` (requested), `status` (HTTP of the document), `navErr`, `finalUrl` (path + search after redirects), `title`, `storedThemeRead`, `htmlDark`, `themeOk` (= `htmlDark === expectDark`), `mainIdCount` (`main#main-content`), `mainCount` (`<main>`), `h1InMain` (h1 + `role=heading aria-level=1` inside `#main-content`), `h1Texts`, `h1Page`, `overflowPx` (`documentElement.scrollWidth − clientWidth`), `sidebarState`, `notFound`, `errorBoundary`, `forbidden` (first permission sentence in main, or null; a loose regex — informational), `head` (first 160 chars of main text), `act` (the target's interaction result), `cErr` / `cWarn` / `cHyd` (console errors incl. pageerrors / warnings / hydration incl. minified React #418/#423/#425, attributed to this load), `cErrExpected404` / `cErrKnown` (console errors subtracted because they belong to an expected 404 document or a target's known failed fetch), `shell` (whether the main = 1 / h1 = 1 rule applies), `expect404`, `ok`, `why` (failed checks), `file` (raw tile under `/tmp/670A-exit-raw/`, not committed), `at`.
- **`console.json`** — `{ group, label, type, text }`; `label` = `group|key|persona|variant`; `type` = `error` / `warning` / `pageerror` / `http-<status>` (a failed response; `text` = `<resourceType> <url>`).
- **`kbd.json`** — the keyboard walks (390 mobile nav, 390 family bar, 1024 DataTable scroller); see § 390 and keyboard.
- **`ids.json`** — ids discovered in the browser + data created through the UI (see § Data).
