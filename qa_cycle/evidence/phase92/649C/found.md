## Orchestrator rulings taken (review fix cycle 1, 2026-11-18)

- **D-14 — an unmatch is refused on a `RECONCILED` statement** (CodeRabbit CR-2). Both unmatch paths (`TrustReconciliationService.unmatch` for a matched line; `StatementLinePostingService.unmatch` for a recorded line, which reverses its rows) refuse with 400 "Statement already reconciled" / "This statement's reconciliation is complete, so its lines cannot be unmatched." The check (`StatementLines.requireNotReconciled`) runs on the statement row after it is locked, in the existing lock order (line → [item/investment/entry] → transactions → statement, 647A — not reordered); the refusal rolls back everything the unmatch had already changed. `completeReconciliation` now locks the statement row (`findByIdForUpdate`) **before** it recalculates, so complete and unmatch are serialised: unmatch-then-complete → G4 sees the unresolved line; complete-then-unmatch → refused. No other path makes a line unresolved again (grep: no un-exclude; the only `UNMATCHED` writes are the two unmatch paths). Red-first: `red-D14.txt`. **For the founder to see:** an attorney who must correct a reconciled month cannot unmatch its lines; the correction is a new posting (and 650A's period lock will govern back-dated postings).

## Review findings declined / deferred (review fix cycle 1)

- **CR-3 / B-M3 — `REPEATABLE_READ` on `calculateReconciliation` / `completeReconciliation`: DECLINED.** They are write transactions. In Postgres a `REPEATABLE_READ` write transaction raises `40001` serialization failures when it updates a row changed concurrently, and this codebase has no retry contract for that. The statement row lock (CR-2 / D-14) serialises the race that changes gate inputs; postings that change the books inside a reconciled period are 650A's lock (`BACKDATED_AFTER_LOCK`).
- **A-M2 — G3 lists one sentence per bad item / investment: KEPT deliberately.** §16.3.4 G3 "names the ledger or the item and both figures"; one sentence per item is how it names each.
- **B-M2 — `TrustIntegrityService` size (≈ 670 lines): DEFERRED.** Extract the message/sentence formatting when 650A adds `BACKDATED_AFTER_LOCK`. Carried → 650A.
