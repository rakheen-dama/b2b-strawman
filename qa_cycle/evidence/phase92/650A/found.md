# 650A — found outside the slice (not fixed here)

| # | Where | Finding | Severity | Suggested owner |
|---|---|---|---|---|
| F-1 | `TrustMonthlyListService.lock` / `posted_at` semantics (ADR-382) | A posting whose transaction stamps `posted_at` (clock.instant()) **before** the lock's `locked_at` but **commits after** the completion's lock reads is in neither the frozen list (READ COMMITTED did not see it) nor `adjustmentsSinceLock` / `BACKDATED_AFTER_LOCK` (`posted_at < locked_at`). The D-5 guard (Σ lines = reconciled creditor total) cannot see it either, because both reads miss the uncommitted row. Narrow (concurrent posting and month-end completion on the same account within milliseconds) and the books stay right; only the "shown against the list" link is lost for that row. A fix needs a design call (e.g. lock the account row in `completeReconciliation`, or compare by commit order rather than `posted_at`). | LOW | design / 652C |
| F-2 | `TrustReconciliationService.completeReconciliation` | `completedAt` is written with `Instant.now()`, not `clock.instant()` (pre-existing). `locked_at` uses the clock (D-6), so the two instants of one completion come from different sources under a fixed test clock. | LOW | any trust slice |
| F-3 | Hibernate JSON `FormatMapper` (tenant `jsonb` columns) | The mapper Hibernate uses for `@JdbcTypeCode(SqlTypes.JSON)` is a Jackson 2 mapper without JSR-310: a `LocalDate`/`Instant` component in a jsonb record fails to serialise ("Java 8 date/time type not supported by default"). 650A stores `CreditorLine.receivedDate` as an ISO string for that reason (brief D-9 fallback). Any later jsonb record with a date must do the same or a `FormatMapper` must be configured (a global config change — deliberately not done here). | INFO | 650B (memo records) |
| F-4 | `Section35DataPackQuery` "Client Trust Balances" section | By consequence of the `client-trust-balances` internals (§16.8.1), the section now lists the Fund line and each open unidentified deposit, and its section total is the account's creditor total (incl. the section 86(3) line on a funding account). No Section 35 code changed. | INFO | 650C (pack v4) |
| F-5 | D-4 concurrent race | Two completions of different reconciliations of the same account to the same month end racing past `findByTrustAccountIdAndPeriodEnd` hit `uq_trust_monthly_list_account_period` → `DataIntegrityViolationException` → 500, fully rolled back. The sequential case is a 400 "Month already locked". 652C's get-or-create removes the second draft at create time. | LOW | 652C |
