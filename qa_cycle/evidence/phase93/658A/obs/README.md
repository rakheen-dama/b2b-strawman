That is the step that consumes the firm's sequence, so it proves the counter claim; the draft's creation itself was not a UI action in this run.
- **Step `reports` ran twice.** The first run hit a Playwright strict-mode error (the report page renders two `#param-asOfDate` inputs, one hidden); the selector was scoped to the visible one and the step re-ran (both runs in `obs-log.txt`; the first made no product change).
