### Architecture Decisions
- **Seeder wired on both call sites, gated on the vertical profile, on the 625E shape with an empty `RECONCILE` so the next definition edit reaches existing tenants by a version bump; the page gates on both capabilities and the controller keeps `FINANCIAL_VISIBILITY`** (§14.3.1, §14.6.6, §14.7.5, [ADR-356](../adr/ADR-356-pack-content-reconciliation.md); §14.12 #1 open).
- **Two additive read-side fields plus one `DELETE` endpoint are the whole backend change for interest runs: a mistaken DRAFT is deleted outright (allocations cascade, audit `interest_run.deleted`, no cancelled status value — deleting a draft has no financial effect because nothing is posted before approval); the wizard stays the single UI and opens on an existing run; no detail route** ([ADR-362](../adr/ADR-362-interest-run-draft-approval-surface.md), R6.10, rulings §9.2; §14.12 #2 decided 2026-11-04).
- **The running balance is computed server-side in posting order over posted rows; non-posted and REVERSAL rows carry null; filters bind after the window in the same query; `Pageable` unsorted with a `countQuery`** ([ADR-361](../adr/ADR-361-client-ledger-running-balance-server-side.md), R6.7; §14.12 #3 open).
- **422 for a well-formed upload whose content cannot be processed; no exception move; grouped with 630C by §8 (same epic, same trust file family)** (§14.3.4).

### Architecture Decisions
- **Rendering omission lives in the template (`conditionalBlock isNotEmpty`), pasted into every client-facing template; the pack `reconcile` keeps the copies in step on existing tenants; four templates, not two; one v11 bump carries the bodies and the `requiredContextFields` declarations (§8)** (§14.3.9, §14.3.11, §14.6.4, R6.5, [ADR-353](../adr/ADR-353-firm-letterhead-settings.md), [ADR-356](../adr/ADR-356-pack-content-reconciliation.md), B12, [ADR-360](../adr/ADR-360-explicit-contract-party-fields.md) consequences).
- **A receipt is one generated document per completed payment event — a nullable FK on `payment_events`, no receipt table, no new category; the number is stored and monotonic; reversal deletes the receipt; AFTER_COMMIT generation with an idempotent lazy fallback; fee-note downloads filter by template id; the whole backend ships in one verified PR** ([ADR-364](../adr/ADR-364-payment-receipt-as-generated-document.md), §14.2.1, §14.3.10, §14.6.2, B2, B6, B8, B11, R6.2, R6.3, R7.4; keys are per-upload UUIDs per [ADR-359](../adr/ADR-359-identity-based-generated-document-keys.md); INTERNAL, no e-mail per [ADR-350](../adr/ADR-350-client-emails-explicit-intent.md)).
- **Period default from `periodEnd`, not `generatedAt`; "today" is `todayInSA()`** (§14.3.12, [ADR-358](../adr/ADR-358-product-wide-sa-business-clock.md)).
- **Pack version chain v11 → v12, each next free at build; the first tenant DDL creates V10** (§14.7, R6.6, §8).
