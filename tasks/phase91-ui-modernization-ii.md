### Architecture Decisions
- **`SettingsSection` lives in `frontend/components` and is layout only**; it carries per-card, page-level, instant and destructive save models side by side without owning any (ADR-394, R4).
- **No family-level h1; each tab keeps its existing h1 through `PageHeader`** (R3) — enforced from 665A on.
- **The mobile family nav is links, not a Select**: no client navigation code, real URLs, one tap to switch (ADR-394).
- **Server-paged mode is additive and type-exclusive with local paging, CSV and selection; DataTable is rendered only from a client wrapper** (ADR-395, refining ADR-369).
